# Data sources

What Flight Chaser reads, from where, and under which terms.

- Live aircraft: [adsb.fi](https://adsb.fi) open data (personal, non-commercial use), and [adsb.lol](https://adsb.lol) — data © adsb.lol contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) — at the same time when `CONTACT` is set (`make` and `npm start` ask for both), and for recordings. Each is asked at its own limit: adsb.fi 0.9 requests a second (its public limit is 1); adsb.lol, which publishes no number, 0.04 (measured: refused at 0.08), with a burst of 3 after a quiet spell. An area one of them could not answer goes to the other at once. Each takes the most urgent request it can make when it has one to spare, so a new view loads from both, and the map keeps moving, slowly, if adsb.fi refuses. Their answers go into one store: the two see 95–99 % of the same aircraft, and a position both report is kept once. adsb.lol's positions that the aircraft itself marks as worthless (GPS jammed: NIC 0 and NACp 0) are dropped, as adsb.fi drops them, so a track never jumps to a false one.
- The past: adsb.lol's tar1090 heatmap files (every aircraft, 10 s) and per-aircraft traces, the same ODbL 1.0 data.
- Aircraft types in the past: the [Mictronics aircraft database](https://github.com/Mictronics/aircraft-database). Contains information from the Mictronics aircraft database, made available under the [ODC Attribution License](https://opendatacommons.org/licenses/by/1-0/). The server downloads it and holds it in memory only.
- Airports: [OurAirports](https://ourairports.com/data/) (public domain). `node tools/build-runways.ts` rebuilds `public/airports/runways.json`: every open runway with both ends placed (14,299 runways of 10,873 airports). The app fetches it the first time the selected aircraft's signal is lost. An aircraft that is no longer heard on its final approach to one of these runways is drawn landing on it, and its card says "Landed": an estimate, as receivers lose most aircraft below their horizon just before they touch down.
- Airport weather reports (METARs) and hazard areas (SIGMETs): the [aviationweather.gov](https://aviationweather.gov/data/api/) Data API (no key). The server fetches them for the client, because aviationweather.gov sends no CORS headers.
- Rain radar: [RainViewer](https://www.rainviewer.com/api.html)'s newest radar frame (keyless tiles), which the client fetches and draws itself.
- Weather model, for the chase's clouds where no report or radar says and its winds aloft (the flight-data frame's wind when an aircraft sends none): [Open-Meteo](https://open-meteo.com/). Weather data by Open-Meteo.com, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), free for non-commercial use. Round the chase the server wants a grid of places 0.25° apart: it asks Open-Meteo once for the places it lacks, keeps each place fresh for 30 min, and holds it up to 2 h. It asks for at most 8,000 calls a day and 4,000 an hour, under Open-Meteo's free 10,000 and 5,000.
- Cloud positions and cloud tops in the chase: Meteosat's cloud mask and cloud top height (the satellite at 0°, a frame every 15 minutes), © [EUMETSAT](https://www.eumetsat.int/) 2026, from [EUMETView](https://view.eumetsat.int/), EUMETSAT's keyless map service. The client fetches the pictures itself: EUMETView sends CORS headers. It asks for the newest frame's time at most every 5 minutes, and for two pictures (3 to 40 KB each) for each frame and place. Flight Chaser reads the numbers back from the pictures' colours and moves the clouds for parallax and wind, so what it draws is changed EUMETSAT data. Two conditions apply to this use: no commercial or operational use, and no redistribution of the original data. Flight Chaser keeps no picture: the test fixtures hold only the service's legends and capabilities.
- The same two products as numbers, when the server has a EUMETSAT key (`EUMETSAT_KEY`, `EUMETSAT_SECRET`: a free account): EUMETSAT's [Data Store](https://data.eumetsat.int/) (`api.eumetsat.int`), collections `EO:EUM:DAT:MSG:CLM` and `EO:EUM:DAT:MSG:CTH`, each a zip of about 0.5 MB holding one GRIB 2 file, there 14 minutes after the frame's time. The server reads them with its own code (`server/grib2.ts`, `server/geos.ts`), keeps the last two frames decoded in memory, and gives the page the box it asks for (`GET /api/wx/sat`). It asks the Data Store seldom: a search of the two collections only once a newer frame can be there and then at most once a minute, a token about every 53 minutes, two downloads a frame (192 downloads a day while a page is open all day). The key, the secret and the token go to `api.eumetsat.int` only, and are never logged. The same terms apply: no commercial or operational use, and no redistribution of the original data; the server writes none of it to disk. The tests that read a real product take it from `data/eumetsat/`, which is not in git.
- Search places: airports and countries from OurAirports, cities of 15 000+ people and their regions from [GeoNames](https://www.geonames.org/) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)); `node tools/build-places.ts` rebuilds `public/search/places.json`.
- Chase map borders, country and sea names: [Natural Earth](https://www.naturalearthdata.com/) (public domain); `node tools/build-map-overlays.ts` rebuilds `public/map/`.
- Terrain / imagery: Cesium ion (Community plan), Re:Earth terrain, Esri World Imagery (optional `VITE_ARCGIS_KEY`), EOX Sentinel-2 cloudless.
- Aircraft photos: [Planespotters.net](https://www.planespotters.net/), each shown with its photographer's credit and a link.
- Flight routes: [adsbdb.com](https://www.adsbdb.com/), asked for the selected flight only.
- Flight search (a flight by its number, [history.md](history.md)): what a ticket number is, from adsbdb.com (it answers for `W43257` as for a callsign); the callsigns an airline flies a route under, from [vradarserver/standing-data](https://github.com/vradarserver/standing-data) ([CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)), one CSV an airline, kept a day; who sends those callsigns now, from the live source's callsign lookup (adsb.fi `/api/v2/callsign/…`, one request for all of them, inside the same request budget as the map); for flights to or from Ben Gurion, the times on the airport's flight board, the Israel Airports Authority's open data on [data.gov.il](https://data.gov.il/); and the days it flew, from the start of adsb.lol's half-hour files (a `Range` request for 0.25 to 1.4 MB of each, 3 MB at most) and the aircraft's trace. All asked by the server, only when a page searches, and kept in memory only.
- Street map: [OpenStreetMap](https://www.openstreetmap.org/copyright) tiles. Buildings and streets in the chase: [OpenFreeMap](https://openfreemap.org/) vector tiles of OpenStreetMap data. © OpenStreetMap contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
- City lights at night: NASA's VIIRS Black Marble, from [GIBS](https://www.earthdata.nasa.gov/engage/open-data-services-software/earthdata-developer-portal/gibs-api).
